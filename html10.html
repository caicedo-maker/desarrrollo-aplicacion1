CSS cascading Styke sheets

CSS (Cascading Style Sheets) es un lenguaje de diseño utilizado para controlar la apariencia y el formato de los documentos HTML (páginas web). En pocas palabras: HTML es la estructura de una página (los huesos), y CSS es el estilo (la ropa, el maquillaje y la decoración).
