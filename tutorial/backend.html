Teoría del Backend

La capa lógica y de procesamiento del servidor

🧠 ¿Qué es el Backend?

El Backend (o lado del servidor) es la capa lógica y de procesamiento de una aplicación. Es todo el código que se ejecuta en un servidor remoto (no en el navegador del usuario) y que se encarga de gestionar la información, aplicar reglas de negocio y comunicarse con la base de datos. Es el "cerebro" de la aplicación; el usuario nunca lo ve directamente.

🎯 ¿Para qué sirve?

Sirve para procesar, almacenar y proteger la información. Sus objetivos principales son:

  • Recibir las peticiones que envía el Frontend.
  • Aplicar reglas de negocio (ej: "no se puede registrar un email duplicado").
  • Comunicarse con la base de datos para guardar, leer, actualizar o eliminar información.
  • Garantizar la seguridad (autenticación, encriptación de contraseñas).
  • Devolver una respuesta al Frontend (generalmente en formato JSON).

Tecnologías que utiliza

  • Lenguajes de servidor: Node.js, Python, PHP, Java, C#.
  • Bases de Datos: MySQL, PostgreSQL, MongoDB.
  • Servidores Web: Apache, Nginx.
  • APIs: REST, GraphQL.

💻 Ejemplo en Código

Este es un ejemplo de un Backend real usando Node.js con Express. Simula recibir los datos del Frontend, validarlos y guardarlos.

// archivo: server.js (Backend - Node.js + Express) const express = require('express'); const app = express(); app.use(express.json()); let usuariosDB = [ { id: 1, nombre: "Ana", email: "ana@test.com" } ]; app.post('/api/registro', (req, res) => { const { nombre, email } = req.body; if (!nombre || !email) { return res.status(400).json({ error: "Faltan datos" }); } const existe = usuariosDB.find(u => u.email === email); if (existe) { return res.status(409).json({ error: "El correo ya existe" }); } const nuevoUsuario = { id: usuariosDB.length + 1, nombre, email }; usuariosDB.push(nuevoUsuario); res.status(201).json({ mensaje: "Usuario registrado exitosamente", usuario: nuevoUsuario }); }); app.listen(3000, () => { console.log("Servidor corriendo en http://localhost:3000"); });
