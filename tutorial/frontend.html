Teoría del Frontend

La capa visual e interactiva de la aplicación web

¿Qué es el Frontend?

El Frontend (o lado del cliente) es la capa de presentación de una aplicación web. Es todo aquello que el usuario ve en su pantalla y con lo que interactúa directamente a través del navegador. Es el "rostro" de la aplicación.

¿Para qué sirve?

Sirve para interactuar con el usuario. Su objetivo principal es capturar información (datos, clics, búsquedas), mostrarla de forma atractiva y asegurarse de que la experiencia de navegación sea intuitiva, rápida y adaptable a cualquier dispositivo (responsive).

Tecnologías que utiliza

  • HTML: Define la estructura y el contenido.
  • CSS: Define el diseño visual (colores, tipografías, márgenes).
  • JavaScript: Define el comportamiento y la interactividad.
  • Frameworks: React, Vue, Angular.

Ejemplo en Código

Este es un formulario simple. Su única función es capturar los datos y enviarlos al backend (simulado aquí con un alert).

<!-- archivo: index.html (Frontend) --> <!DOCTYPE html> <html lang="es"> <head> <title>Ejemplo Frontend</title> </head> <body> <div class="caja"> <h2>Registro</h2> <input type="text" id="nombre" placeholder="Tu nombre"> <input type="email" id="email" placeholder="Tu correo"> <button onclick="enviarDatos()">Registrarse</button> </div> <script> function enviarDatos() { const nombre = document.getElementById('nombre').value; const email = document.getElementById('email').value; if (nombre === "" || email === "") { alert("Por favor, llena todos los campos."); return; } alert(`¡Hola ${nombre}! Tus datos han sido enviados.`); } </script> </body> </html>
