Teoría del CSS

La capa de diseño y estilo visual de la web

¿Qué es el CSS?

CSS (Cascading Style Sheets o Hojas de Estilo en Cascada) es el lenguaje que se utiliza para describir la presentación visual de un documento HTML. Mientras que HTML se encarga de la estructura y el contenido, CSS se encarga de los colores, tipografías, tamaños, márgenes, animaciones y la disposición de los elementos en la pantalla.

¿Para qué sirve?

Sirve para separar el contenido (HTML) de la presentación visual. Sus objetivos principales son:

  • Dar estilo y personalidad a una página web (colores, fuentes, fondos).
  • Controlar el diseño y la maquetación (columnas, grid, flexbox).
  • Adaptar la página a diferentes dispositivos (diseño responsive).
  • Añadir interactividad visual (transiciones, animaciones, efectos hover).
  • Mejorar la experiencia del usuario y la accesibilidad.

Tecnologías y conceptos que utiliza

  • Selectores: Etiquetas, clases, IDs para seleccionar elementos HTML.
  • Propiedades: Color, margin, padding, font-size, display, etc.
  • Modelo de Caja (Box Model): Content, padding, border, margin.
  • Flexbox y Grid: Sistemas modernos de maquetación.
  • Media Queries: Para diseño responsive.
  • Preprocesadores: SASS, LESS (para CSS más avanzado).
  • Frameworks: Bootstrap, Tailwind CSS.

Ejemplo en Código

Este es un ejemplo básico de cómo se aplica CSS a un documento HTML. Se selecciona una clase y se le aplican estilos de color, tamaño y bordes redondeados.

/* archivo: estilos.css */ /* Estilo general del cuerpo */ body { font-family: 'Arial', sans-serif; background-color: #f0f4f8; display: flex; justify-content: center; align-items: center; height: 100vh; margin: 0; } /* Estilo de una tarjeta */ .card { background: white; padding: 30px; border-radius: 20px; box-shadow: 0 5px 20px rgba(0,0,0,0.1); width: 300px; text-align: center; } /* Título dentro de la tarjeta */ .card h2 { color: #003366; font-size: 1.5rem; margin-bottom: 10px; } /* Botón con efecto hover */ .btn { background-color: #007bff; color: white; padding: 10px 20px; border: none; border-radius: 25px; cursor: pointer; transition: background 0.3s ease; } .btn:hover { background-color: #0056b3; }
