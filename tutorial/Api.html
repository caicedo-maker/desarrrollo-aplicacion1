¿Qué es una API?

Una API (Application Programming Interface o Interfaz de Programación de Aplicaciones) es un conjunto de reglas y protocolos que permite que dos aplicaciones se comuniquen entre sí. En pocas palabras, es como un "mesero" digital: tú haces una petición (el pedido), la API la lleva al servidor correspondiente, y te devuelve la respuesta con los datos que necesitas.

En el desarrollo web, las APIs son fundamentales porque permiten que tu página pueda obtener información en tiempo real desde otros servicios sin tener que almacenar todos los datos localmente.
